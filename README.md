## Descripción
Código fuente del Trabajo Fin de Grado, desarrollado en Python sobre el entorno Google Colab. Implementa los modelos de predicción de demanda (baselines, Deep Learning local y forecasting jerárquico con reconciliación MinT) descritos en la memoria, y la simulación de impacto empresarial sobre los costes de inventario.

## Contenido
- "TFG_GIORGI_Memoria_Pablo_Menéndez_2026_05_Codigo Fuente" — Notebook principal con todo el desarrollo.
- "Train_n_val_sets.csv" — Datos históricos.
- "Test_set.csv" — Datos del periodo de test.

## Cómo ejecutarlo
Abrir el notebook en Google Colab, añadir los csv al entorno de ejecución y ejecutar las celdas en orden.
